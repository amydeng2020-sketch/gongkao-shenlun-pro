# 申论复盘一体版（shenlun-review-pro）使用说明

**版本：** v1.5.1
**适用：** 国考/省考公务员考试 · 申论（副省级 / 地市级 / 行政执法类）
**形式：** 一个可直接导入智能体（Agent）的 Skill 技能包 + 内置评分引擎

---

## 一、这是什么

这是一个"申论智能判卷 + 解析 + 复盘"一体化技能。把你的申论作答（文字、答题卡照片、扫描 PDF 任一格式）交给它，它会：

1. **整卷判分**——按当年真题材料逐题评阅，输出每题得分点覆盖、硬性扣分明细、建议分与总分；
2. **单题批改**——题干拆解 → 用哪套方法 → 逐条评点命中了什么、缺了什么、怎么改，最后报档位与分数；
3. **作答解析**——题干没看懂时，帮你逐题拆题、找材料要点、给出示范答案；
4. **二稿对比、学情追踪**——同一题做两稿对比改进，累积个人能力档案。

判分引擎是**纯本地标准库 Python**（零联网、零第三方依赖），评分规则内置，不依赖官方扣分表也能给出稳定的经验校准分。

---

## 二、快速开始（3 步）

### 第 1 步：准备环境
- 需要一个支持运行 Skill 的智能体平台（Coze / WorkBuddy / Claude Code 等，均可运行本技能）。
- 评分引擎只依赖 **Python 3**（系统自带标准库即可，无需 pip 安装任何包）。

### 第 2 步：安装技能
- **Coze 平台**：在 Coze 技能中心/我的技能中上传本技能包（zip 解压导入），加载 `shenlun-review-pro` 即可。Coze 无 MCP 通道时按 `references/coze/coze-runtime.md` 走 CLI 调用引擎。
- **支持 MCP 的平台（WorkBuddy/Claude Code）**：把技能目录加入技能路径，MCP Server（`scripts/shenlun_mcp_server.py`）会自动注册 `shenlun_grade_once` 等工具。

### 第 3 步：发题判卷
直接把"真题给定资料 + 你的作答"发给技能即可，例如：

> 这是某年申论小题，题干：…… 材料：…… 我的作答：……请批改打分。

或一次性上传整套卷的作答（txt / 答题卡图片 / 扫描 PDF）让技能做整卷判分。

## 三、怎么输入效果最好

| 输入格式 | 判分效果 | 建议 |
|---|---|---|
| **清晰纯文字作答（.txt/.md）** | 内容分最准，无 OCR 误差 | ✅ 最推荐，能最真实还原你的表达 |
| 答题卡照片（图片） | 内容分一致；多一道人工转录核对 | 转录后建议对照原件复核 OCR 疑点 |
| 扫描 PDF（转图 OCR）| 内容分一致；同图片需复核转录 | 同上 |

**关键结论（v1.5.1 实测）**：三种格式判小题得分点与内容分**完全一致**，差异只来自两处——
- **错别字归集**：OCR 转录（尤其手写体）误差会让错字计数偏多/偏少，影响归集到作文的扣分（每 3 字扣 1，封顶 3 分）；
- **卷面判断**：只有提供答题卡图片/扫描件才评卷面（轻微 1 分 / 严重 2 分），纯文字无图不评卷面。

> 想让分数最贴近真实阅卷，建议：**文字作答 + 附带答题卡照片**（既内容准，又能评卷面）。

## 四、判分口径说明（务必读，避免误会）

- 五类题型全覆盖：**归纳概括、综合分析、提出对策、贯彻执行（应用文/方案/汇报）、申发论述（大作文）**。
- 得分点**只能来自给定材料**，参考答案仅作校准候选并回材料核验；材料缺失绝不解题。
- **硬性扣分**（错别字/标点/字数/卷面）按**机构通用口径·训练校准**，非国家公务员局官方硬规则。楷体标明，不伪装官方。
- 错别字/标点**全卷归集到最大主体题**（作文 35 分，无作文则最大应用文）记账，小题踩点给分不另扣错别字；语言池封顶 3 分。
- 卷面全卷一次性判断（轻微 1 / 严重 2），无答题卡图不评。
- OCR/图片看不清的字一律标"待核对"，**不据此判漏点或扣分**。
- 最终建议分为**经验校准分**（带档位、区间、置信度），不是官方扣分表，请理性看待分数波动。
